# Projeto Integrador Fullstack - Controle de Estoque

Repositório desenvolvido para o Projeto Integrador da Gran Faculdade, estruturado com foco em arquitetura Fullstack (Backend em Node.js com SQLite e Frontend em React.js).

## 🚀 Funcionalidades
- **Cadastro de Fornecedores:** Gerenciamento com validação de CNPJ e dados cadastrais.
- **Cadastro de Produtos:** Controle por código de barras, categorias, quantidades e validade.
- **Associação:** Relacionamento N para N entre produtos e fornecedores.

## 🛠️ Tecnologias Utilizadas
- Node.js & Express
- SQLite
- React.js
- JavaScript / HTML / CSS
